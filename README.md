# 📱 Encuesta de Emprendimiento CTC

Aplicación móvil desarrollada de manera individual como proyecto final para la obtención del título de **Técnica Laboral por Competencias en Desarrollo de Aplicaciones Informáticas y Digitales** del Centro Tecnológico de Cúcuta (CTC).

La aplicación permite registrar información de estudiantes mediante una encuesta de emprendimiento y ofrece un panel administrativo para consultar resultados, visualizar estadísticas y exportar la información almacenada.

---

## ✨ Funcionalidades

### 👤 Módulo Encuestado
- Registro de información personal.
- Captura de datos de contacto y ubicación.
- Registro de información académica.
- Encuesta de emprendimiento.
- Validación de formularios.
- Resumen antes del envío.
- Almacenamiento de la información en Firebase Firestore.

### 👨‍💼 Módulo Administrador
- Inicio de sesión mediante Firebase Authentication.
- Consulta de encuestas registradas.
- Visualización de estadísticas.
- Indicadores de emprendimiento.
- Exportación de información en formato CSV.
- Cierre seguro de sesión.

## 🚀 Instalación

Clonar el repositorio

```bash
git clone https://github.com/palacio060901-angel/encuesta_emprendimiento_ctc.git
```

Ingresar al proyecto

```bash
cd encuesta_emprendimiento_ctc
```

Instalar dependencias

```bash
flutter pub get
```

Ejecutar la aplicación

```bash
flutter run
```
